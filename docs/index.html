TagWitness

Independent witnesses record which commit each GitHub Actions tag points to, on Arkiv (Tiramisu testnet). If a tag is silently re-pointed — as in the tj-actions/changed-files compromise (CVE-2025-30066) — the history can't be rewritten by the repo owner, GitHub, or us.

1 · Check a workflow

2 · Look up one tag

3 · Recent tag-move alerts

4 · Be a witness (optional)

Connect a wallet on Arkiv Tiramisu (chain 7738577, test ETH from the faucet). Your browser reads the tag from GitHub's API and writes the observation under your address. More independent witnesses = harder to fake.
